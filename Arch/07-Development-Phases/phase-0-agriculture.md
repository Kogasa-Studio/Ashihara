## 阶段目标

Phase 0 的核心不是“做更多内容”，而是建立一条完整、可重复、可理解的农业生存闭环：

`获取种源 -> 育秧/移栽 -> 稻田管理 -> 收获 -> 初加工 -> 食用 -> 继续播种`

当玩家第一次进入世界后，应在不依赖外部 Wiki 的前提下，通过指南书和游戏反馈完成这条闭环。

## 设计支柱

1. **农业优先**：把水稻种植作为前期主轴，而非普通作物的替代品。
2. **低门槛高上限**：新手可以完成基础种植，熟练玩家可通过布局和流程优化提高效率。
3. **文化表达服务玩法**：术语、材料、器具体现日式农业语境，但不牺牲可玩性。
4. **为后续阶段留接口**：Phase 1 的手工业、Phase 2 的建筑和世界探索都从 Phase 0 产物衔接。

## 本阶段范围（In Scope）

- 水稻主流程：种植、生长、收获、基础加工、食用回路。
- 稻田方块与含水逻辑（与普通耕地行为明确区分）。
- 基础农业物品链：种子/秧苗、稻谷、基础米制品。
- 农业相关最小可用世界生成（野生作物或初始资源点）。
- 指南书农业章节：覆盖“第一次种出可食用米”的所有必要说明。

## 非本阶段范围（Out of Scope）

- 大规模村落/城郭结构生成（归 Phase 2）。
- 神道研究、仪式和剧情主线（归 Phase 3~4）。
- 深度 config 体系（Phase 1 收敛后再细化）。

## 里程碑拆分

### M0 - 农业闭环可跑通（必须）

- 玩家能获得并种下水稻（或秧苗）。
- 稻田环境满足生长条件，作物能完成成熟。
- 收获后可获得可加工产物并转化为可食用食物。
- 指南书提供最小闭环指导并可在游戏内访问。

### M1 - 体验稳定化（建议）

- 生长节奏、掉落和产出平衡初步稳定。
- 粒子、音效、基础提示完善，减少“为什么不长”的困惑。
- 初步性能验证（普通生存规模下无明显卡顿点）。

### M2 - 向 Phase 1 的接口预留（建议）

- 与切菜板/研钵/磨粉机流程的输入输出关系定义完成。
- 农业产物可无缝进入基础料理链。
- 术语和命名按统一规范收敛，准备后续重构。

## 验收标准（DoD）

- 新玩家在单人生存中可于一次游戏会话内完成首轮“种植到食用”。
- 指南书农业章节覆盖至少：获取、种植条件、生长阶段、收获、基础加工。
- Phase 0 涉及新类命名符合 `naming-and-code-style.md`；历史遗留命名建立重构清单。
- 关键流程无阻断性 bug（无法种植、无法成熟、无法收获、无法加工）。
