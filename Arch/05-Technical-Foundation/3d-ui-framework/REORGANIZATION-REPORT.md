## 文档使用指南

### 对于AI（我）

**第一次读**：
1. 3d-ui-framework/README.md（快速定向）
2. 3d-ui-design.md（理解架构）
3. pot-gui-spec.md（学习如何应用）
4. 3d-ui-quickref.md（查询模板）
5. decisions/INDEX.md（理解为什么）

**遇到困难**：
1. 查看决策文档理解设计背景
2. 参考pot-gui-spec的代码示例
3. 查看快速参考的FAQ和常见陷阱

**实现过程中**：
- 随时查询3d-ui-quickref.md的API和模板
- 如有新问题，更新此文档的FAQ和常见数值

### 对于用户（校对）

**审查代码前**：
1. 浏览README（了解系统）
2. 快速查看3d-ui-design.md的"集成流程示例"
3. 查看pot-gui-spec.md的交互流程和代码

**审查代码时**：
1. 对照pot-gui-spec.md的组件树结构
2. 检查测试清单中的项目
3. 确认交互流程实现正确

**反馈改进**：
1. 根据DOCUMENTATION-RULES.md的规范提出建议
2. 参考技术决策理解设计选择
