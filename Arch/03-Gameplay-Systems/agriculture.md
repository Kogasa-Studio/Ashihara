## 概述

农业系统是 Phase 0 的主轴玩法，目标是让玩家围绕“稻田-水稻-初加工-食用”形成稳定循环。

该系统不是普通农作物换皮，而是独立的流程系统：

`资源获取 -> 田地准备 -> 播种/移栽 -> 田间维护 -> 收获 -> 初加工 -> 食物产出`

## 玩家体验目标

- 第一次上手：能在短时间内理解“为什么必须用稻田而不是普通耕地”。
- 中期重复：能通过布局优化和批量化操作提升产出效率。
- 长线衔接：产物可自然进入 Phase 1 的工作台与料理系统。

## 核心对象（当前代码映射）

### 方块

- `PaddyFieldBlock`：稻田基础方块，负责核心环境判定（含水相关逻辑，设计名 WaterField）。
- `ImmatureRiceCropBlock`：早期生长段作物（设计名 RiceSeedling 阶段）。
- `RiceCropBlock`：成熟阶段作物（设计名 RiceCrop）。
- `Blocks.WILD_RICE`：野生稻作物（`ChrysanthemumBushBlock` 匿名子类实现）。
- `RiceDryingSticksBlock`：收获后处理中间环节（晾晒）。

### 物品

- `RiceSeedling`：秧苗/苗种入口物品。
- `Paddy`、`STRAW`、`PADDY_PILE`、`BROWN_RICE`、`RICE`：稻作主链中间产物与成品。
- `COOKED_RICE`：基础米食终端之一。

## 生长与产出规则（PRD 级）

### 1) 种植前提

- 必须放置在稻田语义方块上（`PaddyFieldBlock`）。
- 稻田需满足有效含水条件（具体半径与判定逻辑后续与代码同步表格化）。

### 2) 生长阶段

- 阶段 A：幼苗（`ImmatureRiceCropBlock`）
- 阶段 B：成熟（`RiceCropBlock`）
- 不满足条件时：生长停滞，不直接死亡（避免高挫败感）。

### 3) 收获与掉落

- 成熟后可收获基础稻作产物。
- 至少保证“收获后可继续播种”的可持续性。
- 额外产出由平衡参数控制，不在 Phase 0 追求复杂随机机制。

### 4) 初加工链

- 收获产物可进入基础处理（含晾晒或简单处理环节）。
- 处理后可转化为可食用或可进一步加工的材料。

## 数值设计原则（阶段性）

- **稳态优先**：先保证闭环稳定，再做效率优化。
- **信息透明**：玩家能通过指南书和反馈理解“为什么不生长/为什么产量低”。
- **避免硬惩罚**：Phase 0 不引入高损耗机制（如频繁枯死、复杂病害）。

## 与其他系统的接口

- 对 `recipes.md`：定义稻作中间产物的配方输入输出。
- 对 `food-system.md`：定义基础米食最低可用链路。
- 对 `guidebook-system.md`：农业章节必须覆盖“第一次完整收成”。
- 对 `worldgen.md`：确保玩家在正常探索中可获得农业起步资源。

## 指南书最低覆盖清单

- 如何获得第一份秧苗/种源。
- 为什么要使用稻田方块。
- 生长阶段与收获时机识别。
- 收获后如何转化成第一份可食用成品。
