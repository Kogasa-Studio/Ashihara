# 术语表

> **标签**：[与阶段无关]
> **状态**：🚧 编写中

本文档收录 Ashihara 文档体系中使用的专有名词，以及与日本文化相关的核心概念，供文档读者与开发者参考。

---

## 游戏机制术语

| 术语 | 含义 |
|------|------|
| **BuildingComponent** | 建筑系统中的基础构件单元，一个逻辑构件可能由多个 Minecraft 方块组成 |
| **MultiBuiltBlock** | 占据多个方块位置的复合建筑结构 |
| **CuttingBoard** | 切菜板，Phase 0/1 核心工作台之一 |
| **Mortar** | 研钵，Phase 0 核心工作台之一 |
| **Mill** | 磨粉机，Phase 1 核心工作台之一 |
| **PaddyField** | 稻田，Phase 0 核心农业方块 |
| **GuideBook** | 指南书，mod 内置百科全书物品 |
| **产灵（むすび / Musubi）** | mod 核心剧情概念，见下方文化术语 |
| **WildCrop** | 野生作物，自然生成于世界中的可采集植物 |

## 文化与世界观术语

| 术语 | 读音 | 含义与在 mod 中的含义 |
|------|------|----------------------|
| **苇原中之国** | あしはらのなかつくに | 日本神话中的人间国度，mod 世界的名称来源 |
| **産霊 / 産巣日** | むすび (Musubi) | 日本神道中"生成与结合之力"，mod 中作为核心玩法机制 |
| **神道** | しんとう (Shinto) | 日本传统宗教信仰体系，Phase 3~4 的主要主题 |
| **御神体** | ごしんたい (Goshintai) | 神道中神灵依附的神圣物体，mod 中作为特殊物品 |
| **奉納** | ほうのう (Hōnō) | 向神明奉献供品的行为，mod 中作为仪式机制 |
| **祓禊** | はらえみそぎ (Harae-misogi) | 神道净化仪式，mod 中可能作为特殊机制 |
| **畦道** | あぜみち (Azemichi) | 稻田间的田埂小路，mod 中作为装饰性路径方块 |
| **組物** | くみもの (Kumimono) | 日本传统木结构斗栱，建筑系统中的核心构件 |
| **川瓦** | かわらけ (Kawarake) | 素烧陶器，mod 中作为容器与祭祀用品 |
| **障子** | しょうじ (Shōji) | 日式木格拉窗，建筑系统中的窗户方块 |
| **欄間** | らんま (Ranma) | 日式门窗上方的装饰格，建筑系统构件 |

## 技术术语简写

| 简写 | 全称 |
|------|------|
| **BE** | Block Entity（方块实体） |
| **BER** | Block Entity Renderer（方块实体渲染器，本项目首选命名） |
| **TER** | Tile Entity Renderer（历史术语，文档中仅作兼容说明） |
| **ISTER** | Item Stack Tile Entity Renderer（历史术语，现常指手持/界面物品渲染器） |
| **PRD** | Product Requirements Document（产品需求文档） |
| **DataComp** | Data Component（物品数据组件，NeoForge 1.21 新系统） |
